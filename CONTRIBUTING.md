# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. **Fork the Repository**: Create your own fork of this repository to make changes.
2. **Create a Branch**: Create a feature or bug-fix branch (`git checkout -b feature/my-feature`).
3. **Make Changes**: Follow clean coding standards and test your script thoroughly.
4. **Commit Changes**: Write clear, descriptive commit messages.
5. **Push and Submit a Pull Request**: Push your branch to your fork and submit a pull request explaining your improvements.

Thank you for contributing!
