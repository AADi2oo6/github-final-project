# Simple Interest Calculator

A simple interest calculator implemented as a shell script, created for the Coursera "Introduction to Git and GitHub" final project.

## Overview

This project provides a simple Bash script, `simple-interest.sh`, that calculates the simple interest earned or owed on an amount over a period of time given a specific interest rate.

## Inputs

The calculator prompts the user to enter three inputs:
1. **Principal amount** (`p`): The initial amount of money deposited or borrowed.
2. **Annual rate of interest** (`r`): The annual interest rate as a percentage per year.
3. **Time period** (`t`): The time period in years for which the money is invested or borrowed.

## Formula

The simple interest is computed using the standard formula:

```
Simple Interest = (Principal × Rate × Time) / 100
```

Where:
- `Principal` is the principal investment or loan amount.
- `Rate` is the annual rate of interest.
- `Time` is the time duration in years.

## How to Run

Execute the script in a Bash environment:

```bash
bash simple-interest.sh
```
